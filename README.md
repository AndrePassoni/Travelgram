## 📋 About the Project

**Travelgram** is a responsive web application that simulates a travel profile interface, inspired by social media layouts. It features a dynamic gallery and user profile section that adapts seamlessly to different screen sizes.

This project represents an evolution in frontend development, incorporating advanced CSS techniques to ensure a fluid and accessible user experience across mobile and desktop devices. It was developed as part of the **Rocketseat Full-Stack Course**.

## ✨ Features

* **Responsive Design**: A fluid layout that adapts to mobile, tablet, and desktop screens using Media Queries.
* **Modern Layout Models**: Utilization of **CSS Grid** and **Flexbox** for precise element positioning.
* **Modular Architecture**: CSS styles are organized into separate files (`header`, `nav`, `main`, `footer`) and imported into a central `index.css` for better maintainability.
* **CSS Variables**: Implementation of custom properties (variables) in `global.css` for consistent color schemes, spacing, and typography management.
* **Semantic HTML5**: Code structured for better accessibility and SEO.

## 🛠 Technologies Used

The project was built using the following technologies:

* **HTML5**: Structure and semantics.
* **CSS3**: Styling, animations, and responsive layouts.

## 📂 Project Structure

The code is organized to simulate a professional development environment:

```text
Travelgram/
├── assets/          # Images and icons (SVG/PNG)
├── styles/          # Modular CSS files
│   ├── global.css   # Variables and reset
│   ├── header.css   # Header styles
│   ├── nav.css      # Navigation bar styles
│   ├── main.css     # Photo gallery grid/flex styles
│   ├── footer.css   # Footer styles
│   └── index.css    # Main style importer
├── index.html       # Main application file
├── thumbnail.svg    # Project cover image
└── README.md        # Project documentation
```

## 🚀 How to Run Locally

To view the project on your local machine:

1. Clone the repository:
   ```bash
   git clone [https://github.com/AndrePassoni/Travelgram.git](https://github.com/AndrePassoni/Travelgram.git)
   ```

2. Navigate to the project directory:
   ```bash
   cd Travelgram
   ```

3. Open the project:
   Locate the `index.html` file in the folder and double-click to open it in your preferred web browser.
